# Добавление сервисов

Сервисы выбираются в [config/services.toml](../../../config/services.toml). Этот каталог используется основной конфигурацией GitHub Actions. Код программы менять не нужно: редактируйте файл в своей копии GitHub и применяйте изменения через проверенный workflow.

## Готовые наборы

| Набор | Начальное состояние | Область |
| --- | --- | --- |
| `chatgpt` | Включён | ChatGPT / OpenAI |
| `claude` | Выключен | Claude и Anthropic |
| `gemini` | Выключен | Gemini / AI Studio и выбранные API-домены |
| `spotify` | Выключен | Spotify и его CDN |
| `notion` | Выключен | Notion |
| `deepl` | Выключен | DeepL |
| `cursor` | Выключен | Cursor и выбранные служебные домены |

Наборы сверены с официальным [RU hosts GeoHide](https://dns.geohide.ru:8443/static/formats/ru/hosts.txt) 8 октября 2026 года. Присутствие доменов в источнике не гарантирует доступность приложения: список и relay могут меняться, а сервису могут понадобиться дополнительные адреса. Полные новые наборы не имеют подтверждённой приёмки всех сценариев приложения; проверка отдельных доменов или сокращённого набора не подтверждает весь preset.

## Включить готовый сервис

1. В нужном разделе файла замените `enabled = false` на `enabled = true`. Начните с одного сервиса.
2. Сохраните изменение на default branch своей копии. Если автоматическое применение уже включено, заранее установите `SMARTGATE_APPLY_ENABLED=false`, чтобы расписание не применило новый каталог до проверки.
3. Запустите **Actions → SmartGate sync → preview**, `apply=false`, `bootstrap=false`. Проверьте новые домены, найденные маршруты и причины блокировки.
4. Убедитесь, что план укладывается в лимиты. По умолчанию разрешено до 20 операций за запуск и до 100 управляемых записей всего; вне bootstrap доля replace/delete также ограничена `max_change_ratio=0.25` относительно числа owned записей. Большой набор может превысить лимит; не включайте весь список GeoHide сразу. Если нужен другой предел, измените его осознанно в своей копии и повторите preview.
5. Для DNS-адаптера, допущенного к рабочему применению, выполните **sync**, `apply=true`, `bootstrap=false`. Bootstrap нужен только для первоначально пустого назначения, а не для добавления сервиса к существующим маршрутам.
6. На отдельном устройстве проверьте вход, основные функции, файлы и используемое приложение. Затем можно вернуть прежнее расписание.

## Добавить свой набор

Скопируйте один из выключенных разделов и задайте уникальное имя. Например:

```toml
[services.example]
enabled = false
include_suffixes = ["service.example", "api.service.example"]
required_domains = ["service.example"]
exclude_suffixes = []
provider_order = ["geohide-ru", "geohide-eu"]
allow_subtree_rewrites = true
```

Это шаблон с демонстрационными доменами. Замените их адресами вашего сервиса и убедитесь, что выбранный relay действительно их публикует. SmartGate выбирает адреса из источника и проверяет TLS; добавление имени в каталог не создаёт новый relay-маршрут само по себе.

| Поле | Значение |
| --- | --- |
| `enabled` | Включает выбор доменов этого набора |
| `include_suffixes` | Домен и его поддомены; указывайте узкую область |
| `required_domains` | Основные адреса, отсутствие маршрута к которым делает запуск degraded |
| `exclude_suffixes` | Исключения; нельзя публиковать родительское правило, которое перехватит исключение |
| `provider_order` | Приоритет relay-источников, зарегистрированных в конфигурации |
| `allow_subtree_rewrites` | Явное согласие на DNS-правила, которые могут затрагивать поддомены |

Для Gemini намеренно нет общего правила `google.com` или `googleapis.com`. Широкий родительский suffix может перенаправить другие приложения. Общие login/CDN-домены и собственный DNS приложения проверяйте отдельно; набор не обещает полноту всех сценариев сервиса.

## Удаление и обновление

`enabled=false` прекращает выбор новых маршрутов, но при `allow_prune=false` существующие DNS-записи не удаляются автоматически. Выключение набора само по себе не возвращает прежние DNS-ответы. Удаление опубликованных правил требует отдельного просмотренного плана и разрешённого pruning.

Для новых возможностей сервиса сравните его адреса с актуальным источником relay, обновите suffixes и снова выполните preview и проверку устройства. GeoHide может публиковать тысячи доменов; SmartGate использует только явно выбранные наборы.
