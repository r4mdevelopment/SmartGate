# Архитектурные решения

## ADR-001 — периодический Python control-plane

Контроллер получает небольшие источники, делает HTTPS/DNS/TLS проверки и рассчитывает изменения DNS. Постоянно работающий сервер для самого контроллера не нужен. Трафик передаёт внешний relay — GeoHide либо заранее настроенный собственный сервер.

Используется Python 3.12/3.13. HTTPX и dnspython обеспечивают сетевые операции; TOML, CLI, модели и TLS используют стандартную библиотеку. Зависимости закрепляются в lock-файлах с hashes.

Собственный relay является отдельным компонентом и может использовать другой язык без изменения интерфейсов контроллера.

## ADR-002 — независимые DNS и relay adapters

DNS-слой принимает DesiredRewrite и не зависит от происхождения IP. Relay providers возвращают одинаковые нормализованные модели. Это позволяет менять источник маршрутов без переработки синхронизации и каталога.

## ADR-003 — read-before-write и ownership

DNS-профиль может содержать посторонние rewrites. Контроллер изменяет только записи с подтверждёнными IDs и совпадающими предусловиями. Журнал необходим для восстановления после неатомарных API-операций.
