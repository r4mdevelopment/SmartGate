# Проверки готовности

Состояние проверки на **10 октября 2026 года**. **Исходный MVP выполнен для ChatGPT через NextDNS + GeoHide:** есть рабочая синхронизация, подтверждённые DNS-ответы, приёмка на устройстве, сохранение состояния между runners и проверенное расписание. Это не подтверждает работу всех сервисов каталога или любых DNS-провайдеров.

Живые проверки выполнены в отдельно настроенной установке. Публичный репозиторий исходников не содержит её рабочего состояния, ключей и приватных отчётов. Его CI запускает офлайн-тесты; живую приёмку нужно повторить для своей установки.

## Что означают предупреждения

В последних подтверждённых проверках доступно **25 из 27 маршрутов ChatGPT — около 92,6%**, обязательный домен работает. Два необязательных домена, `oaiusercontent.com` и `www.oaiusercontent.com`, не получили свежего подтверждённого маршрута.

Контроллер сохраняет статус `degraded`, когда часть маршрутов недоступна. Успешно проверенная работа с такими предупреждениями может дать зелёный Actions при выполнении всех защитных условий: минимум 85% маршрутов для каждого сервиса, все обязательные домены, подтверждённый журнал и успешные DNS-проверки. Это не означает 100% доступности. [Правила статуса](../operations/actions.md#статусы-deployment).

## Текущий режим и границы проверки

- При `SMARTGATE_APPLY_ENABLED=false` расписание запускает **doctor**, без DNS- и state-записей. В этом режиме выполнены приведённые выше scheduled doctor.
- При `true` расписание запускает **sync с применением**. Ручное применение и повторный sync проверены; последние зелёные scheduled doctor не доказывают применение нового ненулевого плана по расписанию после всех последующих изменений.
- AdGuard Home и Technitium — reference-адаптеры с локальными HTTP-контрактами. Production apply в коде заблокирован; live-приёмка серверов не выполнена.
- Ключи задаются вручную через GitHub Secrets. Автоматического мастера настройки нет. Подробный план читается после локальной расшифровки; публичный Summary показывает только агрегаты.
- Шифрование защищает текущие state и подробные отчёты. Оно не удаляет ранее опубликованный plaintext из старых commits, artifacts или logs. [Границы приватности](../operations/privacy.md).

Результаты относятся к указанным запускам и сценарию. Они не гарантируют доступность внешнего relay сегодня, работу каждого устройства или региона. Для своей установки выполните [первый запуск](../getting-started/quick-start.md) и [приёмку устройства](../getting-started/device-check.md).

Дальнейшие улучшения отделены от обязательного MVP в [планах развития](roadmap.md).
